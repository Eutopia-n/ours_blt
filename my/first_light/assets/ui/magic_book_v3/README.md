# 魔法书界面 v3

整个界面以同一本魔法书为载体：启动封面 → 按 Enter 开书 → 演示目录 → 基础/高阶演示与游戏。目录、每项演示和游戏各状态都保留书页或书本边框，A 逐层返回；原型中在总目录按 A 可回到封面。

本次为美术与交互原型，**没有修改正式固件、游戏逻辑、RTL 或原始人物**。启动 FPGA 工程目前仍会显示原有界面。

## 查看

- `魔法书交互预览.html`：无需联网，浏览器直接打开。键盘 W/S 选择、Enter 打开、A 返回，也可以用按钮和下拉框查看所有页。
- `打开魔法书.gif`：13 帧开书动画预览，从蓝色皮革封面展开为左右书页。
- `封面与内页.png`：封面和目录并排展示。
- `全部页面总览.png`：封面、三个菜单、六项演示、六种游戏状态，共 16 类页面概览。
- `开书动画分镜.png`：动画关键帧。
- `previews/`：22 张 640×480 原尺寸画面，包括九个菜单选中状态。
- `animation/`：13 张开书过程 PNG 帧，供审美和动作参考。

交互原型中的演示按钮只用于浏览布局，不会访问 FPGA 或运行游戏。下拉列表可直接查看游戏准备、运行、暂停、升级、结束和胜利页面。

## 视觉与排版

封面沿用现有小人的深蓝、亮蓝和冰霜色，以暖金书角、书扣和厚纸页形成魔法书外观。现有 32×32 蓝色兜帽小人直接复用，封面为 2 倍、目录为 3 倍最近邻放大。

翻开后的左右页用于承载说明与操作内容：目录左页展示角色，右页放三项选项；复制、颜色键和透明混合用左右两页作对照；矩形填充的数据在左、画面在右。

双缓冲、压力测试与游戏采用横跨左右页的绘制窗口。书角、纸边、页码仍可见；绘制窗口内不添加书脊阴影，避免覆盖像素或影响颜色比较。游戏的准备、暂停、升级和结算面板均放在同一页内。

所有展示均为布局提案。FPS、耗时等没有实测的字段显示 `--`。图形、负载、生命、时间与击杀数是美术排版示例，不是板卡性能或游戏实测数据。

## 后续接入要求

1. **需要重新安排已有内容。** 当前游戏绘制区为 `(8,80,624,360)`，本版建议窗口为 `(46,128,548,266)`。这会影响摄像机可见范围、坐标裁切和 HUD 位置，不能只在原画面上套边框，也不能在未验证时声称新版已经适配运行。最终视口尺寸可在接入时调整。
2. **演示工作量需要重新核对。** 原复制测试图片为 256×192，本次画面中采用示意图；正式接入需要明确保留原负载还是更换图片区域。像素比较、双缓冲撕裂位置、按键和性能采样都要重新检查，不以美术预览作为功能验收。
3. **避免把所有整屏图和动画帧常驻。** 一张 RGB565 全屏图为 614,400 字节。13 帧开书 PNG 是预览参考，不是要求同时放入 DDR 的运行资源。建议后续通过共享书框、组件和可变宽书页生成过渡，或专门设计少量动画数据。
4. **组件数据大小与整套界面开销不同。** 组件图集的 RLE、调色板和描述符合计 8,774 字节，不含全屏书本背景、动画帧、人物、绘制代码、链接对齐和栈。最终程序 RAM、DDR 分配与启动解码时间尚未编译验收，本包不分配新的绝对 DDR 地址。
5. **v3 的 RLE 与 v2 不同。** 本版每个 16 位 token 的 `token >> 6` 是连续像素数，`token & 63` 是调色板索引。解码到完整 256×256 图集。不要用 v2 的右移 5 位解码函数读取本版数据。
6. **保持像素边缘。** 组件与角色采用最近邻整数缩放；书页展开的宽度变化是动画透视预览，不使用平滑滤镜。大标题仍使用原项目字库，但需新增局部文字缩放函数。

图集局部绘制的源地址计算方式为 `ui_base + y*512 + x*2`，源行距始终是 512 字节；透明组件采用现有 `blend_image()` 的 Color Key=0。`ui_base` 由后续接入核对后指定。

## 生成与校验

在 `my/first_light` 下运行：

```powershell
python tools/prepare_magic_book_ui.py
```

需要 Python 3、Pillow，以及同目录已有 `menu_pixel_v2` 组件。生成器只读取 v2 的图片，不覆盖其文件。预览页文字复用项目原点阵字库；外部总览图标题使用 Windows 微软雅黑。

主要绘制函数为 `cover_art()`（封面）、`open_base()`（打开书背景）、`menu()`（目录）、`game()`（游戏页布局）和 `opening_frames()`（开书关键帧）。它们不在现有固件构建路径中。

资源已检查二值 Alpha、透明键、组件与图集像素一致、图集边界、RLE 往返、预览尺寸、原人物文件校验值和 ZIP 完整性。原型的开书流程、选项循环、六项演示跳转、游戏状态切换、返回和动画结束状态已通过离线导航逻辑检查。当前环境无法实开浏览器，尚未完成浏览器中的视觉与按键实操验收。

新增书本美术由代码逐像素绘制，未调用 AI 绘图服务。小人、祭坛、敌人、原字体及 v2 图标沿用项目已有素材与授权，不重新授予许可证。
