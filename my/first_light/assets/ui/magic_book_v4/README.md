# 魔法书界面 v4

这一版重新打磨书本美术：深靛色皮革、做旧黄铜包角、冰蓝宝石封印、雕刻花纹与符文，搭配弯曲羊皮纸、装订线、翻折纸角和丝绸书签。目录改为书中的条目，保留原蓝帽小人；所有演示和游戏状态仍在书页中。

这是美术与交互原型，尚未接入 FPGA。没有修改正式固件、RTL、原始人物或旧版资源。v3 保留供比较。

## 资源与格式

| 文件 | 用途 |
|---|---|
| `png/`、`rgb565/` | 24 个组件：功能图标、光标、面板、封印、书签、皮革与纸张纹理、金属包角、折角与书脊 |
| `book_ui_atlas.png`、`book_ui_atlas.rgb565` | 256×256 组件图集，固定源行距 512 字节 |
| `embedded/book_ui_assets.h` | 调色板、RLE 数据与组件位置 |
| `embedded/book_palette.rgb565`、`book_rle.bin` | 同内容二进制数据 |
| `cover_layer.png`、`cover_layer.rgb565` | 带透明背景的完整封面层，尺寸和放置原点见 `layout.json` |
| `open_book_layer.png`、`open_book_layer.rgb565` | 640×480 透明打开书层，不含桌面背景与页面内容 |
| `spread_background.png`、`spread_background.rgb565` | 640×480 打开书本与背景，便于制作其他内页 |
| `desk_background.png` | 640×480 独立魔法阵背景，可与透明书本层合成 |
| `source/theme.json` | 新版配色 |
| `source/opening_timing.json` | 开扣、封面翻转、跟随纸页、落页四阶段的节奏与逐帧角度 |
| `layout.json`、`manifest.json` | 布局、大小、组件位置与校验信息 |

RGB565 均为小端，透明键为 0，独立图片的源行距为宽度×2 字节；图集的行距始终为 512 字节。透明度只有 0 和 255，不使用平滑缩放。原人物使用最近邻整数放大。

RLE 每个 16 位 token 的 `token >> 6` 是连续像素数，`token & 63` 是调色板索引。解码为整个 256×256 图集，与 v3 相同，与 v2 的右移 5 位格式不同。

组件 C 数据约 11 KiB，精确值见 `manifest.json`。它不包含全屏背景、封面层、展开书层、动画、人物、绘制代码、栈或链接对齐，不能作为整个界面的内存开销。单张 640×480 RGB565 为 614,400 字节；这些整图是制作与接入的输入，尚未分配板卡存储地址。

## 与项目接入有关的限制

所有页面沿用同一本书。双缓冲、压力测试与游戏绘制区横跨左右页，内部不画书脊阴影，避免遮挡像素。复制、颜色键和混合页面以左右页作对照。

现有游戏窗口为 `(8,80,624,360)`，本原型建议 `(46,128,548,266)`，正式接入需要调整摄像机、裁切与 HUD。复制演示的原始 256×192 负载也需要核对；预览里的示意图片与图形不代表板卡实测结果。不能只覆盖边框就视为接入完成。

开书动作改为四阶段：书扣先松开；硬封面按缓起缓停的速度翻开；纸页滞后翻过并逐列弯曲；最后轻微回弹、落到目录。封面、纸页与书体分别绘制，阴影随抬起高度变化。GIF 使用共同调色板，减少颜色跳动，交互原型在播放前预解码动作图片。静态封面、目录、演示与游戏美术保持 v4 原样。

开书动画是审美和动作参考，建议接入时复用书框、封面与纸页，依据时间绘制局部过渡，避免同时保留全部全屏帧。电脑端预览预解码图片的方式不直接用于 FPGA。正式程序内存、速度、按键与图形正确性仍需编译和板上验证。

## 生成

在 `my/first_light` 下运行：

```powershell
python tools/prepare_magic_book_ui_v4.py
```

需要 Python 3、Pillow、项目原字库与人物，以及已有 `menu_pixel_v2` 图标。对比图读取 v3 预览。压缩包保留相对 `my/first_light/` 的资源路径与生成器。

新增绘制函数：`curve()` 绘制像素曲线；`rune()` 绘制装饰性符文；`medallion()` 绘制封印与宝石；`corner_ornament()` 绘制雕刻包角。`cover_art()` 与 `open_base()` 负责书本外观，其余页面复用它们。动画单独放在 `tools/book_opening_animation.py`：`create_opening_frames()` 安排动作节奏，`_project_sheet()` 按细列投影封面和弯曲纸页。这些函数仅用于资源生成，不进入正式固件构建。

资源生成器检查透明度、字库覆盖与 RLE 往返。交付前另核对图集位置、独立图片、RGB565、人物校验值、图层合成与压缩包。浏览器交互只完成离线导航逻辑检查，未做实开浏览器或板上验收。

书本为现有可编辑绘制源上的像素美术修改，未调用 AI 绘图服务。人物、敌人、祭坛、字库与沿用图标遵循项目已有授权。
