## 交互预览

菜单 W/S 选择、Enter 进入、A 返回，保留返回前的选中项；书页右侧的 01/02/03 书签可直接切换基础、高阶和游戏章节。书内页面使用弯曲纸页过渡，进入或离开全屏演示使用短暂淡入淡出。

演示按键按现有源码安排：填充 W 改数量、D 换色、S 换 CPU/FPGA、Enter 切详情；复制 W 改次数、D 换图、S 换 CPU/FPGA、Enter 切详情；缓冲 W 改速度、S 改模式、D 改参考线、Enter 暂停；颜色键 W 开关去背、D 换透明色、S 换背景；混合 W/D 调透明度 ±5、S 换背景、Enter 切 0/128/255 预设；压力 W/S 改数量 ±5、D 切 32/24/16/4 尺寸。

这些操作只改变电脑端排版和参数展示，不执行板卡指令、不产生性能采样。缓冲条、填充与压力对象展示固定时刻的示意状态，暂停与速度数字用于看清排版；不能用原型判断真实撕裂、帧率或处理速度。

游戏页面为静态状态展示。准备/运行/暂停/升级/结束/胜利可用下拉框直接查看，升级 W/S 改选择、Enter 回到运行预览、D 暂停；运行 Enter 暂停，暂停 Enter 继续、A 返回。示例生命、经验、时间等不是一次实际游戏的记录，性能栏保留 `--`。运行态的 WASD 不执行真实移动。

## 设计与项目匹配

章节菜单左页展示当前功能插画，右页保留三项选择。游戏使用独立全屏深蓝界面，升级页采用技能条目，并直接使用项目现有技能图标。游戏状态页增加生命和经验条，运行画面使用纯色底，仅绘制原角色、敌人和掉落物。菜单之间翻页；进入或离开游戏也使用淡入淡出。

复制图片直接按 `basic_demo_data.h` 的算法生成，保持原生 256×192。颜色键和透明混合使用 `effects_demo.h` 的 RGB565 图案、背景和分量混合规则，保留原绘图区位置：复制 `(32,176)` / `(352,176)`，效果窗口 `(48,192)` / `(352,192)`。这些是 CPU 端美术预览，像素一致不代表板卡验收通过。

六项演示的标题与数据皮肤已接入 `software/demo_skin.h`，静态装饰在开始采样前准备；填充、复制、颜色键、透明混合和压力测试图案保留原数值及绘制范围，不以更换测试图案改变工作量。

游戏保留现有视口 `(8,80,624,360)`，无需为了书框缩小画面或改变摄像机尺寸。HUD 放在原视口上方、按键提示放在下方，正式接入仍需编译和核对绘制/刷新行为。压力预览使用原宝石素材示意对象分布，不替代真实压力测试的纹理、采样或成绩。

## 资源与生成

`png/`、`rgb565/` 是独立组件；`book_ui_atlas.png` / `.rgb565` 为 256×256 图集，行距 512 字节。新增书签和生命/经验条组件。透明键 0，小端 RGB565；透明组件 Alpha 仅为 0/255。封面层、打开书层和无内容的书页背景另有 PNG/RGB565 文件。图集 RLE 的长度为 `token >> 6`，颜色索引为 `token & 63`。

旧组件图集未链接进程序。正式资源由 `tools/prepare_book_menu.py` 生成：17 个图层/暂存区，LZ4+RLE 压缩流 17849 字节；初始展开 480678 字节。菜单缓存 `0x01266A00` 至 `0x012FCA00`（结束地址不含）只存一张已绘好的目标页，翻页通过 FPGA 图像复制恢复背景。快照位于 `0x01241000`，用于弯曲叶片；常驻小图标、封面、前封皮和稀疏桌面记录在此前。由于菜单与演示不会同时运行，缓存暂借颜色键/Alpha 和复制演示图片区域，进入演示时会在统计开始前重新加载这两组图片。CPU 主角、冰霜图集和压力 Sprite 区域不会被覆盖。资源池仍为原来的 1 MiB，没有存储整屏动画序列。

动画跟随硬件垂直消隐换页，删除原先换页后再等 20 ms 的步骤。开合目标约 2 秒，章节翻页约 0.53 秒，绘制超时才跳过过期姿态。真实 FPGA 只有填充、复制和 Alpha/颜色键混合，没有纹理缩放；弯曲叶片的投影由 CPU 按扫描行写入，固定书体直接用硬件复制。96 组网格与旧逐条带参考逐像素相同，连续 33 次缓存菜单恢复没有 CPU 填充像素。GCC 栈报告显示 `book_sheet` 2784 字节，当前开书调用链约 3072 字节，在 4 KiB 保留栈内。尚未上板，不承诺实测 60 FPS；串口 `BOOK FRAMES ... MS ...` 可用于核查实际耗时。

在 `my/first_light` 目录运行：

```powershell
python tools/prepare_magic_book_ui_v5.py
```

需要 Python 3、Pillow、原始字库和项目素材，以及 `menu_pixel_v2` 图标；对比图读取 v4 预览。生成器、`book_opening_animation.py` 和 `magic_book_preview_v5.html` 均随 ZIP 打包。

新增 `heading()` / `chapter_tabs()` 统一书内章节，`entry()` 绘制选项，`demo_base()` 绘制全屏演示皮肤，`hint_row()` 排列按键，`bar()` 绘制游戏状态条；`page_turn_frames()` 生成书内翻页参考，`fullscreen_transition()` 生成书本与演示之间的过渡。这些均为资源/原型辅助，不进入固件构建。

正式固件使用 `software/book_menu.h`：`book_init_assets()` 直接在 DDR 中解压，不申请大块程序 RAM；`book_menu_frame()` 绘制目录/章节；`book_animate()` 与 `book_turn()` 分别绘制实时开合和翻页。菜单仍为 W/S 选择、Enter 进入、A 返回；目录按 A 合书。返回菜单保留选中项。进入压力测试已移除显示关闭步骤，两张后台页依次画好后换页。

正式菜单检查使用 `tools/check_book_menu.py`，覆盖实际 C 图层解码、9 种菜单、121 个开书姿态、开合、章节导航、全部入口、压力页初始化/返回、越界和前台页保护。`tools/check_bench_entry.py` 在真实 RTL 上验证连续 3 帧菜单和 3 帧压力画面，无黑屏/混帧/扫描欠载。未运行完整 Sapphire CPU 长仿真；离线浏览器未实开验收，板卡行为未测试。
