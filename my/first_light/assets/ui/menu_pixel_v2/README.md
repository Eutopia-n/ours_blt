# 像素菜单 v2：蓝色冒险者

本版根据“菜单不适配现有小人”的反馈重画。美术以原蓝色兜帽角色为中心：深色石墙、石台、蓝色布旗和冰霜符号构成场景，暖色纸卡承载功能选项。上一版的芯片徽记、科技网格、另画的人物头像和冷色金属卡片不再用于本版。

**现有小人没有修改。** 预览直接使用 `assets/player/walk_32.png` 中第一张 32×32 正面帧，作 3 倍最近邻放大。人物的服装、脸、色彩与原文件保持一致；没有让用户角色迁就新 UI。

原 v1 资源与生成工具均保留，可通过 `风格修改对比.png` 比较。正式项目的固件、RTL、按键逻辑与原始素材均未改动；这些是待接入的资源和效果图。

## 主要调整

1. **角色成为场景主体。** 人物从右上角的小装饰移至左侧石台，正面原帧按整数放大，菜单气质由人物决定。
2. **纸卡替代科技面板。** 选项使用暖色纸面和深色字；选中项通过更亮纸色、金色边与蓝色宝石光标区分。
3. **蓝色来自角色。** 魔法高光与布旗采用深蓝、亮蓝和冰蓝，与斗篷的色相接近，避免原先大面积偏青的科技面板。
4. **图标使用奇幻物件。** 基础与高阶采用书本；复制为卷轴，透明混合为药瓶，颜色键为钥匙，压力测试为成组冰晶。功能标题保持原含义。
5. **三项导航保持。** W/S 上下选择、Enter 打开、A 返回，依旧对应主菜单与两个子菜单。

图标是风格化菜单标记，具体功能由旁边的文字说明，不改变项目的演示内容。

## 接入规格

- 输出仍为 **640×480、RGB565 小端、透明键 0x0000**。PNG Alpha 只有 0 和 255，所有不透明像素编码都不为零。
- 新绘制组件使用 2×2 像素网格。原角色在预览中使用 3 倍最近邻放大，这是明确的整数放大，不会产生插值模糊。
- 本版组件图集与人物图集分开。后续复用已经驻留 DDR 的人物 32×32 帧，避免重复打包角色图集。
- 图集子图源地址为 `ui_base + y*512 + x*2`，源行距固定 512 字节。独立图片的源行距为 `width*2`。`ui_base` 须在后续接入时核对空闲资源区域，当前不指定新的绝对地址。
- 以现有 `blend_image()` 绘制独立图标时，使用 Alpha=255、Key=0、`GFX_BLEND_KEY`。PNG 的透明角需要保留颜色键。
- 九宫格卡片保持四角，边与中心重复填充，不做平滑拉伸。图集中的 `nine_slice_margin` 已是输出像素，无需再乘 2。
- 卡片为 384×72，放在右侧；左侧展示角色与石台。具体位置以 `layout.json` 为准，不使用 v1 的满宽卡片坐标。
- 预览文字仍来自项目已有 `font_cn.h` 与 `font5x7.h`。标题中文作 2 倍缩放、英文作 3 倍缩放；正文中文 14 像素、英文 2 倍 5×7。接入大标题和人物放大需要新增局部的整数缩放绘制函数，现有 `text_at()` / `blend_image()` 不提供自动缩放。

图集解码后占 DDR **128 KiB**。RLE、调色板和描述符共 **9,878 字节**，不含新增绘制代码、对齐和栈；这些数据还未链接到固件，因此不能据此声称程序 RAM 已通过验收。后续接入时需要重新编译并确认剩余 RAM。

RLE 每个 token 为小端 16 位整数：`token >> 5` 是连续像素数量，`token & 31` 是调色板索引。解码结果必须为 65,536 个 RGB565 像素。

## 重新生成和检查

在 `my/first_light` 下运行：

```powershell
python tools/prepare_menu_ui_v2.py
```

依赖 Python 3 与 Pillow。展示板的外部中文说明使用 Windows 微软雅黑，菜单内部始终使用项目已有点阵字形。

新增工具的 `frost_seal_art()`、`banner_art()`、`pedestal_art()`、`rune_art()`、`glow_art()`、`leaf_art()` 分别绘制冰霜徽记、布旗、石台、冰霜符号、台面光和叶片。`menu_preview()` 组合场景；`nine_slice()` 保持边角拼接面板；`encode()` 输出透明键兼容的 RGB565。工具在项目构建流程之外独立运行。

已核对透明色、图集坐标、独立图片与图集像素一致、RLE 全像素往返、现有字形覆盖、九张效果图尺寸及压缩包完整性。效果图为电脑端美术组合，不代表 FPGA 已运行新版菜单。

本版 UI 为原创逐像素绘制，未调用 AI 绘图服务。人物与字库复用原项目资源，继续遵循各自原有授权，不另行授予许可证。
