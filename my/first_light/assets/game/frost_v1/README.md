# 冰霜魔法 · 游戏美术包

整体延续蓝帽主角、深蓝界面、冰蓝魔法和旧金装饰。原人物完整保留，游戏使用纯色背景；新增美术不恢复地砖、祭坛或围墙。

本轮按反馈重点重绘了经验、守卫、统领和法环：经验改为饱满的青绿晶簇，守卫采用宽肩冰铠与盾牌，统领采用法冠、骨白面具、紫袍、魔法书和冰杖，法环采用中心透明的符文轮廓。红心重绘为红色心形、金色边缘和清晰的治疗十字。

已接入源码的内容：五类敌人各两帧动作、六种独立技能图标、三个经验档次、两帧法环和重绘红心。敌人属性、出生规则、经验奖励、掉率和技能效果保持原规则。蝙蝠每 6 个逻辑 tick 换帧，其他敌人每 12 tick 换帧；不新增对象池或每个敌人的动画状态。

9 帧扩展资源位于 `reserve/`：命中星芒两帧、召唤符文两帧、符文宝箱关闭/开启、蓝晶药瓶、霜晶花、秘库钥匙。这些资源已完成美术制作，未进入固件，也没有增加对应玩法。

## 内存与集成

运行图集共 73728 字节（72 KiB），比取消背景后的 25 帧版本增加 22528 字节（22 KiB）。背景不保存图片，仍不加载此前 472 KiB 的场景数据。扩展素材不随程序加载。压缩数据和固件编译占用见 `validation.json` 与 `runtime_manifest.json`；资源池总范围和双帧缓冲尺寸未改。

新美术、动画选择和图标映射已进入项目源码，并通过固件、FPGA 完整编译和 150MHz 时序检查。当前下载文件位于 `releases/fullscreen_art_20261116/`，也已包含六个全屏演示皮肤、菜单绘制优化及压力页切换修复。游戏继续全屏和纯色背景，全屏 HUD 新皮肤仍为原型。加入书本后程序静态占用 119256 字节，预留栈后剩余 7720 字节；游戏图集尺寸不变。旧构建保留，板上表现尚未验收。

在项目 `my/first_light` 中执行：

```powershell
python tools/prepare_frost_game_art.py
python tools/build.py firmware
python tools/prepare_magic_book_ui_v5.py
python tools/preview_frost_game_art.py
```

编辑 `assets/game/source/frost_v1/` 中的 PNG 后，执行 `prepare_game_assets.py` 可直接打包修改；`prepare_frost_game_art.py` 会重新绘制这些源 PNG。每帧 Alpha 为 0/255，避免引入不支持的半透明纹理；运行时的全局 Alpha 仍由现有 FPGA 图形引擎处理。

人物来自用户原素材；新霜系素材由项目内像素绘制工具制作。原 Kenney CC0 素材和许可、原红心源图保留在上级 `source/` 中用于追溯，不改变其许可归属。
