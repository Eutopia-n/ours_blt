# 图像复制演示素材

- `supertuxkart.png` 取自 QwertyChouskie 的《SuperTuxKart》Cocoa Temple 赛道截图。使用图源页的 330×186 缩略图，按 4:3 居中裁剪并缩放。 [原图与署名](https://commons.wikimedia.org/wiki/File:SuperTuxKart_in-race_(2018).png) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- `0ad.png` 取自 Wildfire Games 的《0 A.D.》港城截图，原截图由 Pureon 拍摄。使用图源页的原图，按 4:3 居中裁剪并缩放。 [原图与署名](https://commons.wikimedia.org/wiki/File:0A.D.screeny.png) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

工程保存的是 72×54 裁剪图。固件使用 16 色索引压缩和双线性放大，在 DDR 中恢复成 256×192 RGB565 复制源。每张截图的裁剪图和固件素材沿用各自图源页的许可。
