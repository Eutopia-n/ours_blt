# Ti60 全屏演示皮肤与菜单绘制优化 · 2026-11-16

六项演示正式接入像素图标、深色面板和金色边框，演示和游戏继续全屏。测试用图案、绘制尺寸、颜色键/Alpha 算法、压力负载及统计窗口保留；游戏继续使用已接入的 72 KiB 冰霜素材与纯色背景。游戏新版 HUD 排版仍为原型。

## 为什么原先会卡

原先每帧由 CPU 逐点重画静态桌面和菜单，弯曲页逐窄条纵向访问 DDR；换页后还额外等 20 ms，容易错过 60 Hz 垂直消隐。新版只保存一张目标页，翻页时用现有 FPGA 复制单元恢复，固定书体也改为硬件复制，桌面仅补画少量装饰。弯曲页按扫描行连续写入；没有添加缩放器、提高时钟或存储整屏动画序列。

菜单缓存与复制/效果图片错时复用原 1 MiB DDR 资源池。进入演示前清除就绪标志，在采样开始前重新加载；已验证两组图像逐字节恢复。CPU 主角、游戏图集和压力纹理区不受覆盖。

## 验证

Efinity map/interface/pnr/pgm 完整通过，CPU 仍为 150 MHz，640×480 HDMI；未改生产 RTL。程序静态占用 119256 字节，保留 4 KiB 栈后剩余 7720 字节。栈分析版本的程序与交付版本逐字节相同，开书调用链约 3072 字节。

实际 C 检查覆盖 9 种菜单、121 个开书姿态、96 组新旧网格逐像素对照、33 次缓存菜单恢复无 CPU 填充、共用图片恢复、全部入口与开合。基础/高阶回归覆盖全部 256 档透明度等 1040 组效果图片及单/双缓冲操作。真实显示 RTL 连续扫描 3 帧菜单与 3 帧压力页，无黑屏、混帧、前台写入、欠载或读错。

本轮未运行完整 Sapphire CPU 长仿真，未上实体板卡、未烧录。预览 GIF 播放时间不能作为板卡帧率。开书目标约 2 秒、章节翻页约 0.53 秒；若一帧超过刷新预算，会跳过过期姿态。

## 上板后具体核对

1. 使用本目录 BIT 临时配置，确认封面、Enter 开书、基础/高阶菜单、A 返回/合书。
2. 打开原工程 115200 串口，记录 `BOOK FRAMES ... MS ...`；如仍卡顿，先记录这两项，区分绘制慢与显示异常。
3. 六项演示逐一进入，确认金色标题图标和深色面板已更新；复制页换图、透明混合调透明度，返回菜单后再次进入，确认图片未被缓存破坏。
4. 进入压力测试，应从完整菜单直接切到完整压力页；W/S 加减 5、D 换尺寸。实际 FPS 和 MAX60 以板卡读数为准。
5. 双缓冲演示默认单缓冲、STEP=8，其有意展示的撕裂需按 S 切换双缓冲后比较。
