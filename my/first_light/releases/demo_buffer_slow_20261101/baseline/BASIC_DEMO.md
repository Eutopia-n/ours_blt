# 基础演示：手动切换版（2026-11-01）

本版填充/复制默认 CPU、S 手动切换 CPU/FPGA，不自动轮换，按键功能说明使用中文。
游戏、压测五步调节与 MAX60 判定、共享驱动、全部生产 RTL、PLL、DDR、HDMI 和约束保持任务起点内容。压测默认 32×32，按 D 降档。
颜色键与 Alpha 页的硬件效果演示见 [高阶两页说明](EFFECTS_DEMO.md)。
三个入口仍是矩形填充、图像复制、双缓冲。

## 对应赛题与演示顺序

1. 矩形填充：展示 RGB565 Solid Fill 和大量可重复运动方块；观察同负载 CPU/FPGA FPS、FILL_US 和 SPEEDUP。
2. 图像复制：左侧为独立 DDR 源图，右侧为 Block Copy 结果；切换两张图和复制负载。进入 BUS 详情视图，显示 OP、SRC、尺寸、读写突发和等待周期；DST 仅从界面隐藏，C 驱动仍下发目的地址。配合实际 AXI/FIFO 仿真波形说明系统总线访问。
3. 双缓冲：进入默认单缓冲撕裂，S 手动切换双缓冲防撕裂，再按 S 切回。使用同一组三根运动竖条，观察横向错位与完整边缘，不自动轮换。OUT_HZ 从硬件显示刷新计数按实际时间测量，与渲染 FPS 分开。

基础菜单名称与游戏/高阶入口不变。现有顶层为 `rtl/competition_top.v` 中的 `competition_top`：
RISC-V 通过 APB（基址 0xF8100000）配置图形寄存器，图形子系统通过 AXI 直接读写 DDR；按键、UART、DDR 和 HDMI 输出端口保持。
CPU/图形时钟 150MHz，DDR fabric 100MHz，DDR PHY 400MHz，像素时钟约 25.208MHz。
复位仍使用原 DDR 校准/锁定条件和原同步逻辑。本版没有修改任何时钟域、仲裁器或复位路径。

## 操作

矩形填充：

- W 循环切换每帧 8、32、64、128 个 32×24 方块。
- D 切换颜色组合。
- S 手动切换 CPU/FPGA。默认 CPU，不会随时间改变路径；两路各采样 30 帧，切换时从相同的第 0 帧位置序列开始。
- Enter 在画面和 BUS 详情间切换；详情视图将运动方块放到右侧，避免覆盖文字。
- A 返回。

图像复制：

- W 循环切换每帧 1、2、4、8 次复制。
- D 切换风景图与城市图。
- S 手动切换 CPU/FPGA；Enter 切换画面和 BUS 详情；A 返回。
- 每次命令复制完整 256×192 图到右侧固定目标。LOAD 表示每帧执行的复制次数，不表示同时显示多张不同图片。

双缓冲：

- 进入默认“单缓冲 撕裂”；S 在单缓冲撕裂与双缓冲防撕裂之间手动切换，没有定时切换。顶部 A/B 页卡片与显示/绘制标记已删除。
- 单缓冲直接更新实际正在显示的前台显存；双缓冲只写后台显存，完整绘制后使用原驱动在垂直消隐末端交换页面。
- 两种模式均在原帧边界确认后约 8ms 更新同一组三根竖条，位于有效扫描中段。此相位安排使扫描与前台写入的冲突便于观察，不是预先画一张上下错位图；双缓冲的显示页不参与本次写入。
- W 循环切换每帧 16、32、64 像素步长，默认 32。D 开关参考横线。
- Enter 暂停/继续运动；暂停后竖条不再更新，撕裂现象也随之停止。双缓冲换页或单缓冲同页节拍继续，不切换模式。
- A 返回。退出与模式/参考线切换时先从硬件状态恢复后台页，完整界面重画只发生在后台；返回后两页绘制相同菜单，再等待操作。
- 场景采用稳定底色，仅擦除并重画旧竖条区域，避免用整屏明暗闪烁代替撕裂。原双缓冲驱动、扫描时序、图形 RTL 和其他演示保持不变。

## 指标口径

- CPU FPS / FPGA FPS：各自最近一个 30 帧窗口的实际呈现帧率，包含 HUD、换页等待和后续区间中的 UART 开销。没有将结果固定为 60，也没有用任务耗时倒数冒充呈现 FPS。
- FILL_US / COPY_US：每帧命名任务批次的平均微秒数。排除初始化、源图上传、源图预览、清背景、文字和换页等待；包含实际驱动提交及写入完成。两路均在计时前排空此前 CPU 写入，在计时内执行同一写入完成屏障；FPGA 驱动等待最终 AXI B 响应。
- RENDER_US：场景准备、任务、计数器读回和实际 HUD 更新的完整平均渲染时间，不含换页等待。
- SPEEDUP：相同配置 CPU 平均任务周期数 / FPGA 平均任务周期数，保留两位小数。两路未形成有效样本前显示“-”。
- MB/S：当前路径有效任务字节数 / 任务耗时，十进制 MB/s，显示整数。Copy 是有效复制吞吐量；读入再写出产生的总线传输量不能与它混为一项，也不将它称为全 DDR 利用率。
- AR/AW：本任务批次的硬件读写突发次数；RD WAIT/WR WAIT：已有硬件等待计数器的任务前后差值，单位为 150MHz 图形时钟周期。显示 30 帧平均值。两者均排除清背景、CPU、HUD 和 HDMI 流量；CPU 路径显示“-”，避免将硬件计数为零解释为 CPU 没有 DDR 访问。
- OP、SRC 为该页命令类型与源资源地址；尺寸、LOAD 在顶部显示。填充源地址显示“-”。详情页不显示 DST，但驱动仍配置该寄存器。
- AXI MAX 16×32BIT、FIFO 16 / RTL CONFIG 是现有 RTL 配置说明，明确不是 FIFO 瞬时占用量或实测峰值。
- 双缓冲页 SWAPS 只统计当前模式中真正完成的前后台交换，单缓冲保持 0。单缓冲也发送同页请求，等待原帧边界确认，仅用于下一次扫描中段写入的节拍，不更换显示页，不能消除此前已经发生的撕裂。
- WAIT_US 是上一轮等待帧边界确认的时间，两种模式都有；FRAME 是运动相位帧号。MISSED 是硬件显示刷新计数的跳跃次数，不是撕裂次数，0 不表示无撕裂。诊断值延后一轮显示，模式/参考线切换会重置当前诊断。
- OUT_HZ：硬件显示帧计数的时间差测量，约每秒更新；开始测量前显示“-”。画面配置为 640×480 RGB565，显示同步由原硬件模块生成。

改变负载、图像、颜色或画面/详情布局会清空两路旧样本。仅手动切换 CPU/FPGA 保留同配置读数，并重新开始当前窗口。尚未测量过的路径显示“-”；要形成 SPEEDUP，应在相同负载下手动测完两路。方块的初始相位、速度可重复，不使用逐次变化的随机种子。

## DDR 存储与边界

- 图 1：0x012C0000，98,304 字节。
- 图 2：0x012D8000，98,304 字节。
- 占用范围：[0x012C0000, 0x012F0000)，共 192KiB，位于现有 1MiB 资源池内。
- 现有围墙缓存结束于 0x012AA000。编译期检查保证不与围墙重叠，且不超过原资源池。
- 测试图在首次进入复制页时生成一次；游戏素材和启动上传不变。没有增加片内图像数组，也没有扩容程序 RAM。
- CPU 复制采用对齐的 32 位连续读写；两路读同一源、写同一目标，源步长 512 字节，目标步长 1280 字节。

## Burst/FIFO 的证据与答辩说明

`reports/basic_bus_waveform.png` 和 `.svg` 来自实际 RTL 仿真的 CSV，不是示意绘图，不是实板截图。
波形展示 AWLEN=15（16 拍）、WVALID/WREADY、WLAST、FIFO 占用及入/出队。
重点观察下游等待时 FIFO 保存数据，WVALID/数据在反压下保持稳定，握手后出队；相邻突发之间仍有合法的地址/状态开销，不能宣称整个复制过程每拍都有写数据。

同一基线 RTL 的独立测试覆盖两张源地址、两页缓冲、256×192 尺寸、512 字节源步长；每次各 1536 个读、写突发，与 98,304/64 相符。
同时执行全 DDR 字节对照、空操作/非法步长/越界拒绝、随机 AXI 反压和 FIFO 越界断言。
这些证据说明当前实现的传输与缓存行为；没有生成“关闭 FIFO”或“1 拍/16 拍”的性能对照。

若后续要求在板上显示 FIFO 运行峰值，需要新增只读监测寄存器。本版遵守“不改其他部分”，保留共享 RTL，仅展示已有硬件统计和仿真证据。
