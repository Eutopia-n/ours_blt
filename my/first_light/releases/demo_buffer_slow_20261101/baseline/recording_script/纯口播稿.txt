【00:00—00:20 项目介绍】
这是我们基于易灵思 Ti60F225 实现的 RISC-V 与 FPGA 异构二维渲染系统。RISC-V 负责交互、游戏逻辑和命令下发，FPGA 负责位块搬运与混合，结果经 DDR 帧缓冲通过 HDMI 输出。下面按赛题要求展示基础功能、总线优化和高阶效果。

【00:20—01:00 矩形填充】
首先是纯色填充。每个方块都是由 C 驱动下发的填充任务，可以改变数量和颜色。保持负载不变，按 S 手动切换 CPU 与 FPGA，两条路径采用相同的运动序列。这里同时显示实际呈现帧率和批次填充耗时。如果两路帧率都接近显示刷新上限，仍可以通过微秒数和耗时比观察性能差异。

【01:00—01:50 图像复制】
图像复制使用两张独立存放在 DDR 中的二百五十六乘一百九十二 RGB565 图片。左侧是源图，右侧是复制结果。现在切换图片，并在相同图像、相同复制次数下比较 CPU 和 FPGA。COPY_US 是每帧全部复制任务的耗时，SPEEDUP 是两路耗时之比，MB/S 表示有效复制吞吐量；LOAD 表示每帧复制次数。

【01:50—02:30 总线与 FIFO；波形部分须标注 RTL 仿真】
详情页展示操作类型、源地址和尺寸；在 C 驱动中补充展示目的地址，五项指令信息仍完整下发。加速器通过 AXI 直接访问 DDR，读写突发由硬件实际统计。这里单次复制包含九万八千三百零四字节。下面是同一 RTL 的仿真波形：AWLEN 为十五表示十六拍突发；FIFO 在下游等待时保存待传数据，在握手时出队。

【02:30—03:00 双缓冲】
进入时默认单缓冲，在显示器扫描过程中直接写前台显存，竖条上、下部分出现位置错开。现在按 S 手动切到双缓冲：后台完整绘制后，在帧边界换页，竖条保持完整。两种模式使用相同图案和速度，不会自动切换。OUT_HZ 显示实际输出刷新率，与渲染 FPS 分开。
〔仅在实测支持时补读：当前显示刷新率约为六十赫兹，满足赛题最低输出要求。〕

【03:00—03:35 颜色键】
颜色键页面固定使用 FPGA。左侧是完整原图，右侧按指定透明色去背。关闭颜色键时，矩形背景重新出现；打开后，匹配透明色的像素跳过写入，保留目的背景。这里支持黑色和品红色两种选择。页面还从 DDR 读回八个采样位置，核对边缘和图案结果。

【03:35—04:20 Alpha】
Alpha 页面同样固定使用 FPGA，颜色键关闭。左侧是不透明参考，右侧读取前景和背景，按权重执行 RGB565 通道混合。页面显示的是透明度，硬件前景权重等于二百五十五减去透明度。透明度为零时完全不透明，为二百五十五时完全透明。W、D 每次调整五，Enter 可快速切换三个预设。

【04:20—05:05 压力测试】
独立压力页同时开启 Alpha 和颜色键，所有运动 Sprite 都提交给硬件。我们逐步增加固定尺寸的数量，每次按键变化五个。只有连续三十帧满足完整渲染预算、并且没有漏过显示刷新，才记录这一尺寸的 MAX60。当前通过数量和帧率以屏幕实测值为准；切换尺寸后重新测量。
〔选读，实测后替换：在【尺寸】下，本次测试达到【数量】个 Sprite，并通过连续三十帧窗口。〕

【05:05—05:50 游戏；后期密集片段需标注同版本、游戏内时间、原速】
最后是互动游戏。RISC-V 负责移动、碰撞、自动攻击和升级逻辑，人物、怪物及效果图像由 FPGA 执行颜色键与 Alpha 合成。这里展示持续移动、敌人追踪以及较密集场景，并保留 FPS、实际绘制元素和 MAX60 指标。游戏的元素统计包含不同绘制类型，不能直接等同于全部使用硬件 Alpha 的 Sprite 数量。

【05:50—06:00 结束】
以上展示了位块填充与复制、总线突发和 FIFO、双缓冲输出，以及硬件混合、颜色键和互动游戏。性能结论以同一版本的实板读数为准。
