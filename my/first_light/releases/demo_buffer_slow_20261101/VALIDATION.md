# 双缓冲低速默认版（2026-11-01）

仅将基础“双缓冲”页三档运动步长从 16/32/64 降为 8/16/32 像素/帧；每次进入默认低速 8（原默认 32）。W 按 8→16→32→8 循环。模式/参考线切换保持当前速度，退出重进恢复低速。

进入仍默认单缓冲撕裂，S 手动切换双缓冲防撕裂，不自动切换；D 参考线，Enter 暂停/继续，A 返回。其他演示、游戏、高阶、压测、共享驱动、字体、全部生产 RTL 和时钟/DDR/HDMI/约束经源文件哈希核对保持。
