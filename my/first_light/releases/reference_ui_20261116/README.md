# 本地预设对齐版 · 2026-11-16

本版以 `assets/ui/magic_book_v5/魔法书交互预览.html` 为视觉依据，覆盖正式工程中的魔法书菜单与全屏游戏界面。参考 HTML 保留原样。旧版下载文件保留在各自发布目录。

## 已改内容

- 封面、九个菜单状态与游戏准备页：RGB565 下与本地预设逐像素一致，包含原始字号、对齐、人物、边框和底部按键。
- 动画：采用预设的封扣动作、封面转动、弯曲纸页、前后层次和分段缓动。开书目标 2.4 秒、章节翻页目标 0.64 秒，按实际经过时间推进；过期姿态会跳过。结束后显示原始分辨率菜单。
- FPGA：新增菜单专用扫描线合成模块，负责纹理缩放、明暗、透明混合和后台帧写入，CPU 提交书页姿态。原有填充、复制与 Alpha/颜色键引擎保留。
- 游戏：准备、运行 HUD、暂停、强化、失败及胜利全部接入正式绘制；保留原人物和玩法，采用已更新的经验、守卫、统领、红心与法环。暂停恢复后重新加载被临时指令覆盖的图集，清除底部旧文字。
- 演示继续全屏；游戏场景保持纯色 `0x1085`，背景纹理为 0 字节。菜单和游戏复用原 1 MiB DDR 素材池，整屏动画帧序列不进入固件。

静态菜单已逐像素对齐。运动过程采用定点计算、紧凑纹理和分段阴影，存在少量采样与明暗差异，不能称为动画全部像素与浏览器相同。

## 验证边界

已执行实际 C 资源解码、封面/菜单/准备页与 HTML 像素对照、119 个开书中间姿态、双向章节切换、48 次游戏状态/选项及双缓冲交替、暂停恢复后的图集和人物检查。

FPGA 仿真使用六组真实指令，覆盖开书早期、弯曲中段、淡入结束、正反翻页及暂停遮罩；在随机 DDR 等待下逐像素对比。联合扫描检查连续 4 帧菜单与 4 帧书页，压力入口检查连续 3 帧菜单与 3 帧压力页，均无黑帧、混帧、前台写入、扫描欠载或读错。全部 7227 个素材 ROM 字通过实际 APB 读出验证。原填充/复制/混合和基础/高阶演示回归通过。

完整 Efinity 编译、最终时序及固件大小以随包 `validation.json` 和 `evidence/` 为准。CPU 仍为 150 MHz、HDMI 640×480、程序 RAM 128 KiB，未修改引脚和时钟约束。

本轮未进行完整 Sapphire CPU 长仿真，未烧录或测试实体开发板。仿真耗时和预览中的 FPS 不代表板卡实测。

## 上板后的核对顺序

1. 使用本目录 BIT 配置后，Enter 开书、W/S 选择、Enter 进入章节，A 返回。最终字体与本地 HTML 对照。
2. 原串口为 115200，记录 `BOOK FRAMES ... MS ...`。如仍有卡顿，请保留这两项及所处页面，下一步据此检查绘制耗时和显示换页。
3. 进入游戏，确认准备、运行、暂停/继续、强化及结算的新界面。检查暂停恢复后人物正常、页脚没有旧字，返回菜单后书页正常。
4. 进入压力测试，确认从完整菜单直接切到完整压力页，再返回；原尺寸、数量和 MAX60 操作保留。
