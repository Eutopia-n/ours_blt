## 上板查看

1. 下载本目录 BIT 或 HEX，确认封面正常，Enter 开书。
2. W/S 选择基础与高阶，Enter 进入；A 返回并确认选择保留，目录 A 合书。
3. 高阶选择 SPRITE 压力，确认菜单直接切换到完整压力页，无黑屏；W/S 数量仍按 5 改变，D 按 32→24→16→4 切尺寸，A 返回。
4. 进入填充/复制/缓冲和游戏，确认仍全屏；移动、暂停、升级与结算不出现书框，游戏背景保持纯色。

若压力入口仍异常，先确认下载文件来自本目录，再观察串口是否到达 `BENCH INIT` 和 `BENCH RUN`；若停在中间，记录 `FAIL`/`TRAP` 行及屏幕状态，用于区分绘制或换页失败。
